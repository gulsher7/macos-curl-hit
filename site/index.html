What it does

Built for one question that a browser's network tab can't answer: what happens when you send this request a thousand times instead of once?

🔁

Replay any curl

Paste one straight from your browser's network tab. Headers, bodies, auth, cookies and multi-line pastes all work as-is.

⚡

Hit it in parallel

Up to 50 requests in flight at once, to see how the endpoint behaves when they overlap rather than queue.

📈

Find the rate limit

Ramp mode climbs through concurrency levels and tells you, in one line, exactly where the 429s begin.

🎲

Vary every request

Randomise chosen headers, query parameters or body fields per hit — keeping each value's shape so validation still passes.

🔍

See what was sent

Every hit keeps its own request snapshot, copyable as a runnable curl. Trace any failure back to what caused it.

🔒

Stays on your Mac

No database, no account, no telemetry. Sandboxed, with exactly one entitlement: outgoing network.

Ramp mode

Guessing a concurrency number and re-running by hand is slow. Ramp climbs a ladder and reads the result for you.

stage  sent   ok   429   p95      req/s
x1     16     16   0     166ms    6.4
x4     16     16   0     158ms    25.4
x8     16     16   0     160ms    50.1
x16    16     8    8     165ms    96.9

Rate limited at 16 parallel — 8/16 got 429.

It separates four cases that look alike in a results list but need completely different fixes:

  • 429s appear — a configured quota, named at the level it starts.
  • 5xx or dropped connections — the server is breaking, not throttling.
  • No errors but p95 bends — queuing. A capacity finding, not a limit.
  • Nothing bends — no limit up to the top rung, with peak throughput.

Advanced mode

Replaying one identical request only exercises the paths that accept duplicates. Advanced mode takes the request apart — every header, query parameter and body field, including nested JSON — and gives each one a fresh value per request.

 ☑  header   X-Device-Id    7F3A1B20-44C1-4E8A-…   Same shape ▾   5P2X6D66-88J6-3R5V-…
 ☐  header   Content-Type   application/json
 ☑  query    trace          abc123def456           Same shape ▾   76b34b9c5c6f
 ☑  body     user.id        48217                  Digits     ▾   35286
 ☑  body     user.email     someone@example.com    Same shape ▾   kzjtqfr@qykirmn.lcv
 ☑  body     token          ca8b7d1d1ae846cbbf…    Hex        ▾   f6bb494ef9cef0f0…

Values keep their shape, not just their length. If a server validates “32 hex characters” or “numeric id”, random mixed characters get rejected by the validator and you end up testing the validator instead of the endpoint. Digits stay digits, separators stay put, hex stays hex, and a JSON number is still sent as a number.
